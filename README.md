# 🌾 Farm2D RPG 🎮

**Farm2D RPG** là một game nông trại 2D được phát triển bằng Unity (C#), kết hợp yếu tố xây dựng, trồng trọt, câu cá, khai thác và chiến đấu.

## 🛠 Tính năng chính

- 🏡 Xây nhà và phát triển trang trại.
- 🎣 Câu cá và sưu tầm sinh vật biển.
- ⛏️ Khai thác mỏ, chặt cây và thu thập nguyên liệu.
- ⚔️ Đánh quái và bảo vệ nông trại.
- 📦 Hệ thống inventory và quản lý tài nguyên.
- 🗺️ Bản đồ mở với nhiều khu vực khám phá.
